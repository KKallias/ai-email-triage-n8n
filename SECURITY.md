# Security

## Credentials

This project uses external services through n8n credentials.

API keys, OAuth tokens, Gmail credentials, and Google credentials must not be committed to this repository.

## Safe Sharing

Before exporting an n8n workflow for public use, review the exported file and confirm that it does not contain private email addresses, tokens, secrets, or other sensitive values.

Use your own credentials when reproducing the workflow.

## Portfolio Scope

This repository demonstrates workflow design and integration logic. It does not provide shared credentials or access to the original connected accounts.
